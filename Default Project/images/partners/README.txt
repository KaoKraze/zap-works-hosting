Source partner logos (originals). The site does NOT load these directly any more.

The live site uses optimised copies in images/logos/<name>.webp (same names, WebP, max 112 px tall),
which are about 4 MB smaller in total. The list of logos, their order and how each one is displayed
(white silhouette "mono" or greyscale "gray") is in js/main.js (PARTNERS).

To add a logo: put the original here, export a WebP (transparent background, ~112 px tall) to
images/logos/, then add an entry to PARTNERS in js/main.js.
